# أكاديميا — Student Follow-up
نظام عربي RTL لإدارة الطلاب والحضور والمدفوعات وبوابة ولي الأمر والطالب.

## التشغيل
ارفع الملفات إلى استضافة ثابتة مثل Vercel. المشروع يستخدم Supabase JS من CDN ومهيأ للاتصال بمشروع Supabase المحدد في config.js.

## الوظائف
- تسجيل حساب بالبريد وكلمة المرور.
- إدارة الطلاب والرسوم الشهرية.
- تسجيل الحضور: حاضر، غائب، متأخر، بعذر.
- تسجيل المدفوعات.
- ربط حساب ولي الأمر والطالب بالبريد الإلكتروني.
- بوابة ولي الأمر لعرض بيانات الطالب والحضور والمدفوعات.
- بوابة الطالب لعرض سجل الحضور.
- نسخة احتياطية يدوية إلى قاعدة البيانات وملف JSON.

## ملاحظات
- استخدم publishable key فقط في المتصفح ولا تضف service_role key.
- النسخ الاحتياطي المجدول التلقائي غير مفعّل؛ المتاح حاليًا نسخة يدوية.
- يجب مراجعة سياسات RLS في Supabase قبل استخدام التطبيق مع بيانات حقيقية.
